# Telco Customer Churn Prediction

## Project Description
Customer Churn is a major challenge in the telecomunication (telco) industry. Churn occurs when customers stop using the services of one telecom provider and switch to another. If companies can predict which customes are likely to leave in advance (for example, within the next few months), they can take proactive measures such as targeted promotions, discounts, or improved customer support to retain them.

For telecom companies with millions of customers, even a small reduction in the chrun rate can result in a significant increase in revenue and custome retention.

Churn analysis involves studying the relationship between **customers**, **services/products**, and the **likelihood that a customer will descontinue the service**. The goal here is to detect early signals that indicate a customer may leave and allow the company to take preventive action.

## Dataset
This project uses **Telco Custormer Churn** dataset from Kaggle, which contains information about a fictional telecom company that provides home phone and internet services.

Each row in the dataset represents a customer, and each column contains attributes describing that customer and their services.
The raw data contains 7043 rows (customers) and 21 columns (features), where 17 are categorical variables and 4 are numeric variables.
The dataset includes information such as customer demographics, subscribed services, billing details, and contract type.

The “Churn” column is our target.

## Problem
The main objective of ths project is to **develop a machine learning model** that predicts whether a customer is likely to churn. To achieve this, the project includes:
1. Exploratory Data Analysis (EDA)
2. Data Processing
3. Feature engineering
4. Model training and evaluation

The final goal is to identify customers who are at risk of leaving so the company can implement retention strategies.

## Machine Learning Models
In order to achieve this goal, various machine learning models must be studied. Therefore, given the nature of the problem, it was decided to train the following models:
1. Logistic Regression
2. Random Forest 
3. XGBoost
4. Support Vector Machine (SVM)
